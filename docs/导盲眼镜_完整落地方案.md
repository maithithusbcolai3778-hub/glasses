## 3. ESP32-P4 端需做的补充

### 3.1 新增 `/play` 接口

- **方法**：`POST /play`
- **Content-Type**：`application/octet-stream` 或 `audio/pcm`
- **Body**：16kHz、16-bit、单声道 PCM 原始数据
- **行为**：
  1. 读取 HTTP body 到缓冲区
  2. 调用 `audio_speaker_play(pcm, len, timeout)` 播放
  3. 返回 `200 OK` 或错误信息

> 限制：单次音频建议不超过 5 秒（约 160KB），避免内存不足。复杂长句可以拆成多段发送。

### 3.2 可选：新增 `/imu` 专用接口

当前 `/status` 已经包含 IMU 数据，可以直接复用，无需新增接口。

## 4. PC Agent 端完整流程

### 4.1 主循环（建议 2~5 fps）

```text
while True:
    1. GET /snapshot.jpg      → 获取当前画面
    2. GET /status            → 获取 IMU yaw/pitch/roll
    3. YOLO 推理              → 得到检测框 + 类别 + 置信度
    4. 后处理 + 决策          → 生成中文提示文本
    5. TTS 合成 PCM           → 生成音频
    6. POST /play             → 发送给 ESP32 播放
    7. sleep(200~500ms)
```

### 4.2 YOLO 推理

```python
from ultralytics import YOLO
model = YOLO(r"D:\YOLO_CUSTOM\runs_custom\guide_glasses_80\weights\best.pt")
results = model(frame, device=0, conf=0.4)
```

当前模型可识别类别：

| 中文含义 | 类名 | 用途 |
|----------|------|------|
| 行人 | person | 避障 |
| 汽车/公交车/卡车/摩托车/自行车 | car/bus/truck/motorcycle/bicycle | 避障 |
| 红绿灯 | red_light / green_light | 过马路 |
| 盲道 | blind_road | 路径引导 |
| 斑马线 | crosswalk | 过马路 |
| 反光锥/路障/警示柱 | reflective_cone/roadblock/warning_column | 避障 |
| 电线杆 | pole | 避障 |

### 4.3 空间方向计算

画面坐标 → 真实转向角度：

```text
转向角度 ≈ (目标中心 X - 画面中心 X) / 画面宽度 × 水平视场角
```

- 画面宽度：800 像素
- 水平视场角（FOV）：OV5647 默认约 60°，建议实测标定
- 结合 IMU yaw：用于记录相对转向，比如“请向左转 15 度”

### 4.4 决策规则（优先级从高到低）

| 场景 | 判定条件 | 播报示例 |
|------|----------|----------|
| 紧急危险 | 近距离车辆/行人位于画面中央 | “正前方有汽车，请立即停下。” |
| 左侧危险 | 车辆/行人位于左半屏 | “左前方有行人，请注意。” |
| 右侧危险 | 车辆/行人位于右半屏 | “右前方有自行车，请注意。” |
| 盲道引导 | 检测到 blind_road | “检测到盲道，请沿盲道直行。” / “盲道向左偏，请向左转 10 度。” |
| 斑马线 | 检测到 crosswalk | “前方斑马线，请注意来往车辆。” |
| 障碍物 | 检测到 roadblock / reflective_cone / pole | “右前方有路障，请向左绕行。” |
| 安全 | 什么都没检测到 | “前方安全，可慢行。” |

### 4.5 TTS 方案

推荐优先级：

1. **edge-tts**（免费、中文自然、离线可用）：
   ```bash
   pip install edge-tts
   edge-tts --voice zh-CN-XiaoxiaoNeural --text "前方有行人" --write-media out.mp3
   ```
   再用 ffmpeg 转成 16kHz 16-bit PCM：
   ```bash
   ffmpeg -i out.mp3 -ar 16000 -ac 1 -f s16le out.pcm
   ```

2. **pyttsx3**（完全离线，但音色较机械）

3. **gTTS**（需要联网，Google 服务可能不稳定）

### 4.6 大模型兜底（可选，后续接入）

当满足以下任一条件时，把原图 + 检测结果 + IMU 姿态传给 Qwen-VL：

- 多目标遮挡，决策规则无法判断
- 置信度普遍低于 0.4
- 出现未训练过的复杂场景

示例 prompt：

```text
你是一副辅助视障人士出行的智能眼镜。当前画面检测到的目标如下：
- 左前方 5 米有行人，置信度 0.82
- 正前方 8 米有汽车，置信度 0.91
- 地面检测到盲道

IMU 姿态：yaw=12°, pitch=-5°, roll=2°

请给出一句简洁的中文安全引导提示，不超过 20 字。
```
